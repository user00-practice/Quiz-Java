## 問題1

下のパソコンの在庫データから、クラスを作成してください。クラス名は `Item` です。  
クラスにはフィールド変数を作成します。  
**フィールド変数は他のクラスからアクセスできないようにしてください。**

| 型番            | 品名          | 価格        | 発売日             | 在庫の有無         |
|----------------|--------------|------------|-------------------|--------------------|
| `String number` | `String name` | `int price` | `LocalDate date`  | `boolean stock`    |
| X015           | PC-5613      | 112,000    | 2020/10/31        | 有                 |
