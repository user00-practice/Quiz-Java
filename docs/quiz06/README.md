## 問題４

次のプログラムは二つの整数値を読み込んでその和と差を表示するものですが、  
実行しても和と差が求められません。  
プログラムを修正して正しく和と差を求めるようにしてください。(Sample04)

```java
// 二つの整数値を読み込んで和と差を表示

public class Sample04 {

    void main(String[] args) {

        IO.println("x と y の和と差を求めます。");
        
        int x = Integer.parseInt(IO.readln("x の値："));
        int y = Integer.parseInt(IO.readln("y の値："));

        IO.println("x + y = " + x + y);
        IO.println("x - y = " + x - y);
    }
}
```

### 実行結果

```text
x の値：10
y の値：3
x + y = 13
x - y = 7
```
